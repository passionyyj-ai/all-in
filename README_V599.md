# ALLIN V5.9.9 — 팀당 정확히 4명

## 적용 순서
1. V5.9.8을 적용한 기존 DB에서 ALLIN_V599_Exactly_Four_Members.sql 전체를 실행합니다.
2. 배포 ZIP의 웹 파일로 교체한 뒤 앱을 닫았다가 다시 엽니다.
3. 시리즈가 진행 중이면 종료한 후 팀을 다시 생성합니다. 기존 팀은 SQL 실행만으로 바뀌지 않습니다.
V5.9.8 SQL을 아직 적용하지 않았다면 이전 hotfix → ALLIN_V598_Four_Teams.sql → ALLIN_V599_Exactly_Four_Members.sql 순서로 실행하세요.

## 변경 내용
- 균형·랜덤 편성 모두 팀당 정확히 4명.
- 2팀 최소 8명, 3팀 최소 12명, 4팀 최소 16명. 부족하면 기존 팀을 유지하고 오류 안내.
- 자동: 편성 대상 8~11명은 2팀, 12~15명은 3팀, 16명 이상은 4팀. 8명 미만은 생성하지 않음.
- 정원 초과자는 대기로 남김. 예: 14명 자동은 4명씩 3팀과 대기 2명, 18명 자동은 4명씩 4팀과 대기 2명.
- 초과 인원이 있을 때 균형 편성은 정원 인원을 먼저 무작위로 고르고, 선택한 인원 안에서 포지션·실력 균형 편성.
- 기존 대기자를 제외하는 규칙 유지. 참석 16명 중 대기 4명이면 편성 대상은 12명입니다. 대기자를 먼저 팀에 배정해야 4팀 생성이 가능합니다.
- 수동 팀 이동은 기존대로 가능. 팀당 4명 보장은 팀 생성 시 적용.
- 최종 팀원 수를 DB에서도 확인하고 정확히 4명이 아니면 전체 편성을 되돌림.

## 검증
로컬 화면·인원 검증·RPC 전달·기존 화면 테스트와 SQL 정적 검사를 수행했습니다.
실제 Supabase 실행과 점수 저장·청구·실기기 통합 테스트는 수행하지 않았습니다.
