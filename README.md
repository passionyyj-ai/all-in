# ALLIN V4.7

## 신규 기능
1. 회원 명단 제외 전체 초기화 버튼
2. 초기화 전 확인 문구 `초기화` 입력
3. 4자리 초기화 PIN 입력
4. 최종 확인창 후 초기화 실행
5. 회원/관리자/월 회비 설정 유지
6. 회비·입출금·모임·참석·팀·경기·게임비·시리즈 데이터 삭제
7. 연도 마감 및 다음 연도 이월잔액 생성
8. 같은 연도 중복 이월 방지

## 초기 초기화 PIN
1111

## 적용
1. ZIP 내용을 GitHub all-in 저장소에 덮어 업로드
2. Supabase SQL Editor에서 ALLIN_V47_Reset_YearCarry.txt 실행
3. 관리자 로그아웃 후 다시 로그인
