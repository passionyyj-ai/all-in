# ALLIN V5.9.5

## 변경 사항

- 회원별 실력 등급(1~5) 추가
- 기존 회원의 실력 등급은 중급(3)으로 자동 설정
- 포지션 균형 편성 시 주 포지션과 실력 합계를 함께 균등 배분
- 3팀이 1승씩 기록해 같은 팀으로 재경기할 경우 최종 패배팀 게임비를 기본 게임비의 2배로 적용
- 시리즈 게임비 직접 입력 기능을 사용해도 3팀 재경기 2배 규칙 유지

## 적용 순서

1. Supabase SQL Editor에서 `ALLIN_V595_Skill_Balance_ThreeTeam_DoubleFee.sql` 실행
2. GitHub Pages 운영 파일 전체 교체
3. 설치된 앱을 완전히 종료한 뒤 다시 실행
4. 총무 화면의 회원 수정에서 회원별 실력 등급 입력

기존 회원·회비·모임·경기·게임비 데이터는 삭제하지 않습니다.
