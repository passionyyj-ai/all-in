# ALLIN V5.5.3 게임횟수 수정

## 원인
- 회원용이 실제 경기 수가 아니라 미납 청구 행 수를 표시
- 총무용이 `three_team_series_id`를 집계하지 않음
- 총무 화면의 납부/미납 필터에 따라 게임횟수가 달라짐
- 회원용 개인조회 함수가 게임비 전체 현황을 그대로 반환

## 수정 기준
게임횟수는 선택한 월에 게임비가 확정된 고유 경기·시리즈 수입니다.

- 일반 단판: `game_id` 기준 1경기
- 2팀 다전제: `series_id` 기준 1경기
- 3팀 단판 시리즈: `three_team_series_id` 기준 1경기
- 납부 여부가 바뀌어도 게임횟수는 변하지 않음
- 회원용은 로그인한 본인의 경기만 표시
- 총무용은 해당 월의 전체 클럽 경기 수 표시

## 적용
1. Supabase SQL Editor에서 `ALLIN_V553_Game_Count_Fix.sql` 실행
2. GitHub 운영 저장소 파일 교체
3. PC는 Ctrl+Shift+R, 아이폰 앱은 완전히 종료 후 재실행
