# ALLIN V5.5 / ALLIN Studio V4.3

## 핵심 변경사항
- 회원용 로그아웃 기능 유지
- 회원용/총무용 PWA 분리 유지
- 정확히 3팀인 경우 단판 승자연전 시리즈 자동 적용
- 한 팀이 2승하면 우승 확정
- 우승팀을 제외한 두 팀이 최종 패자 결정전
- A/B/C팀이 1승씩이면 시리즈 회차 자동 초기화
- 최초 회차 정상 종료: 최종 패배팀 1인당 2,000원
- 초기화가 한 번이라도 발생한 뒤 종료: 최종 패배팀 1인당 4,000원
- 재초기화가 반복되어도 최종 게임비는 4,000원 유지

## 적용 순서
1. Supabase SQL Editor에서 `ALLIN_V55_Three_Team_Series_Update.sql` 실행
2. GitHub 운영 저장소 파일을 V5.5 파일로 교체
3. PC는 Ctrl+Shift+R
4. iPhone 홈 화면 앱은 완전히 종료 후 다시 실행
