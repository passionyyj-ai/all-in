# ALLIN V6.0.0 — 게임비 관리

## 적용 순서
1. 기존 V5.9.10 DB에서 ALLIN_V600_Game_Fees_Only.sql 전체를 Supabase SQL Editor로 실행합니다.
2. 배포 ZIP의 웹 파일로 교체하고 앱을 닫았다가 다시 엽니다. 기존 config.js 연결 설정을 유지하세요.
3. 총무의 게임비 메뉴와 회원의 나의 게임비 화면을 확인합니다.

## 변경 내용
- 월 회비 메뉴·설정·납부 등록·재무 현황·연도 이월 화면 제거. 홈도 게임비 중심으로 변경.
- 납부/미납 상태·납부액·잔액·입금 확인 버튼·상태 필터 제거.
- 일반 시리즈, 3팀 시리즈, 기존 단판 경기별 게임비 삭제 버튼과 확인창 추가.
- 삭제한 게임비는 관리자/회원 화면, 월 합계, 공유에서 제외. 경기 결과·팀 명단·경기 횟수 기록 자체는 유지.
- 삭제자·시각·대상 행은 DB game_fee_deletion_history에 보존. 원본 행도 deleted_at으로 보존하며 재저장으로 되살리지 않음.
- 삭제는 선택한 시리즈의 게임비 전체에 적용. 월별 수동 조정은 특정 시리즈와 연결되어 있지 않으므로 별도로 유지.
- 회원별 게임비 금액 수정·사유·수정 이력 유지. 수정 화면도 게임비 금액만 관리.
- 공유는 날짜·시리즈·패배팀·대상별 게임비·총액만 표시. 납부 상태, 미납 합계, 입금 확인 요청 문장 제거.
- 기존 납부 여부와 관계없이 삭제되지 않은 게임비 전체를 조회·공유.
- 4팀 편성, 팀당 4명, 대기자 포함 옵션, 팀 스냅샷과 동기화 유지.

## 데이터와 검증
과거 회비·납부·입출금 테이블/기록은 이관 호환과 기록 보존을 위해 DB에 남겨 두며 새 화면에서는 사용하지 않습니다. 기존 SQL 파일을 다시 실행하면 옛 함수로 되돌아갈 수 있으므로 이번 SQL을 마지막에 적용하세요.
실제 운영 DB를 변경하거나 사이트에 배포하지 않았습니다. 로컬 검증 범위는 VALIDATION_V600.txt를 확인하세요.
Studio ZIP은 전체 소스와 SQL이 들어 있는 편집용 프로젝트입니다.
