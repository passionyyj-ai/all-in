# ALLIN V5.9.6

## 변경 내용

- 참석 인원과 관계없이 `자동 / 2팀 / 3팀` 중 팀 수를 직접 선택할 수 있습니다.
- 자동은 기존 규칙(12명 미만 2팀, 12명 이상 3팀)을 유지합니다.
- 중간 이탈자는 팀 선택에서 `대기`로 변경한 뒤 다시 편성하면 제외 상태가 유지됩니다.
- 대기 인원은 기존 규칙대로 경기 횟수와 게임비 대상에서 제외됩니다.
- 진행 중인 시리즈가 있으면 팀 재편성과 팀·대기 변경을 막습니다.

## 적용 순서

1. Supabase SQL Editor에서 `ALLIN_V596_Manual_Team_Count_Exclusions.sql`을 실행합니다.
2. GitHub 운영 저장소에 배포 ZIP의 파일을 모두 교체합니다.
3. 모바일 앱을 완전히 종료하고 다시 실행합니다.

## 사용 방법

1. 팀 편성 영역에서 `팀 수 자동`, `2팀`, `3팀` 중 하나를 선택합니다.
2. 포지션·실력 균형 또는 완전 랜덤 편성을 누릅니다.
3. 중간에 빠지는 회원은 해당 회원의 팀 선택을 `대기`로 바꿉니다.
4. 시리즈가 진행 중이면 먼저 종료 또는 취소한 뒤 다시 편성합니다.
