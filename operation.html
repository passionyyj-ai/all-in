팀 편성

자동 배분 후 관리자가 직접 변경
포지션 균형: 공격·토스·좌수비·우수비를 고려합니다.
완전 랜덤: 포지션과 관계없이 참석자 전원을 무작위로 균등 배분합니다. 남는 인원도 각 팀에 자동 배치되어 대기자가 생기지 않습니다.
관리자 직접 지정: 팀 생성 후 각 회원 옆의 팀 선택 메뉴에서 원하는 팀으로 즉시 이동할 수 있습니다.

일요일 경기 운영

참석자 전원 강제 배분 → 경기 → 패배팀 게임비 → 재편성

1. 팀 편성

진행 중인 시리즈가 있으면 팀을 다시 편성하거나 회원의 팀을 변경할 수 없습니다. 참석자는 모두 팀에 배정되며 대기인원은 발생하지 않습니다.

2. 시리즈 시작

2팀: 다전제 · 3팀: 단판 승자연전

3. 시리즈 경기 진행

팀 수에 맞는 경기 방식 자동 적용

4. 종료된 시리즈

최종 패배팀 게임비 자동 청구

입출금 등록

참석자 직접 수정

3팀 단판 점수 입력

모든 경기는 단판입니다. 최초 회차에서 종료되면 최종 패배팀은 1인당 2,000원, 1:1:1 초기화가 한 번이라도 발생한 뒤 종료되면 1인당 4,000원이 청구됩니다.

세트 점수 입력

동점은 저장할 수 없습니다. 한 팀이 2승 또는 3승에 도달하면 시리즈가 종료됩니다. 일반 게임은 최종 패배팀이 1인당 2,000원을 부담합니다. 세트 점수가 정확히 8:0이면 즉시 콜드패로 시리즈가 종료되고, 0점 팀은 1인당 4,000원을 부담합니다. 종료 후 팀을 다시 편성합니다.

운영 데이터 초기화

삭제 후 복구할 수 없습니다.
