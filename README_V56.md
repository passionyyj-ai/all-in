# ALLIN V5.6 회원 대리 운영 모드

## 변경 사항
- 회원용 `경기 운영 화면` 버튼에서 관리자 아이디/비밀번호 입력 제거
- 로그인한 회원의 이름과 PIN을 다시 검증한 후 운영 모드 진입
- 운영 화면은 참석 관리와 경기 운영만 표시
- 회원관리, 회비, 미수, 시스템 초기화 메뉴 숨김
- 현재 대리 운영자 이름 표시
- 회원 화면으로 돌아가기 버튼 제공
- 회원 로그아웃, 개인 회비 조회, 게임횟수 수정, 3팀 시리즈 기능 유지

## 운영 모드 제공 기능
- 참석 현황 조회 및 총무 직접 수정
- 팀 자동 편성 및 회원 팀 이동
- 2팀 다전제 경기 운영
- 3팀 단판 승자연전 경기 운영
- 경기 결과 입력과 게임비 자동 청구

## 제한 기능
- 회원 추가/수정/삭제
- 회비 및 입출금 관리
- 게임비 미수 관리
- 모임 신규 생성
- 시스템 초기화와 연도 이월

## 적용
이번 변경은 별도 SQL이 필요하지 않습니다.
GitHub 운영 저장소 파일을 교체한 뒤 캐시를 새로고침하세요.
