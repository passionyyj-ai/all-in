# ALLIN V5.5.1 안전 패치

## 원인
V5.5에서 새로 추가한 `three_team_series` 또는 `three_team_games` 조회가 실패하면
전체 `loadAll()`이 중단되어 기존 회원정보까지 빈 화면처럼 표시되는 문제가 있었습니다.

회원 데이터가 삭제된 것은 아닙니다.

## 수정
- 기존 회원·모임·회비·경기 데이터와 3팀 확장 데이터 조회 분리
- 3팀 SQL 미적용 또는 권한 오류가 있어도 기존 화면 정상 표시
- 확장 기능 오류 시 3팀 기능만 비활성화
- SQL 적용 안내 문구 표시
- 회원용 로그아웃 유지
- 회원/총무 PWA 분리 유지

## 적용 순서
1. GitHub 운영 저장소 파일을 V5.5.1 파일로 전부 교체
2. PC: Ctrl + Shift + R
3. iPhone: 앱 완전 종료 후 다시 실행

3팀 기능을 사용할 경우에만 Supabase에서
`ALLIN_V55_Three_Team_Series_Update.sql`을 실행합니다.
