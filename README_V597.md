# ALLIN V5.9.7

## 변경 내용

- 미수 메뉴의 단톡방 공유 방식을 회원별 월 합계에서 시리즈별 공유로 변경했습니다.
- 일반 2팀 시리즈, 3팀 단판 시리즈, 기존 단판 경기를 각각 별도 카드로 표시합니다.
- 각 시리즈 카드에서 `단톡방 공유` 또는 `문구 복사`를 사용할 수 있습니다.
- 공유문에는 경기일, 시리즈명, 패배팀, 대상 회원, 회원별 금액, 납부 상태, 총 청구액과 미납 합계가 포함됩니다.
- 회원별 합계 입금확인·수정·이력 기능은 기존대로 유지합니다.
- 특정 시리즈와 연결할 수 없는 총무 수동 조정액은 회원별 합계에만 반영하고 시리즈 공유문에는 포함하지 않습니다.

## 적용

- Supabase SQL 업데이트는 필요 없습니다.
- GitHub 운영 저장소의 파일을 ZIP 내용으로 교체한 뒤 앱을 완전히 종료하고 다시 실행합니다.
