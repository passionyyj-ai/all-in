# ALLIN V5.9 - 심판 기능 제거

## 변경 내용
- 심판 선택 입력 완전 삭제
- 회원 화면의 오늘의 심판 표시 삭제
- 시리즈 시작 시 심판 조건 및 검증 삭제
- 참석 인원 수와 관계없이 두 팀만 선택하면 시리즈 시작 가능
- 참석자는 팀 또는 대기로 자유롭게 배정
- 대기 인원은 시리즈 팀 명단에 포함되지 않으므로 게임비와 경기횟수에서 제외
- 시리즈 진행 중에는 팀 ↔ 대기 변경 잠금 유지

## 적용 순서
1. Supabase SQL Editor에서 `ALLIN_V59_Remove_Referee.sql` 실행
2. GitHub Pages 저장소의 배포 파일 전체 교체
3. 설치된 ALLIN 앱을 완전히 종료
4. 브라우저에서 한 번 접속하거나 앱을 다시 실행하여 V5.9 캐시 적용

## DB 참고
기존 referee 컬럼은 과거 버전과의 호환성을 위해 물리적으로 삭제하지 않습니다.
V5.9부터 생성되는 시리즈에는 referee 값이 항상 NULL로 저장됩니다.
