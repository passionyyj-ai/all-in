# ⚽ 올인 족구단 V4.1

## 변경
- 일반 패배: 1인당 2,000원
- 8점 차 이상 콜드게임 패배: 1인당 4,000원
- 동일 회원 게임비를 월별 합산 표시
- 같은 회원의 월 미납 게임비를 `합계 입금확인` 한 번으로 처리
- 입금 확인 시 수입 내역에는 합계 금액 1건으로 반영

예: 일반 패배 2회 + 콜드게임 패배 1회 = 8,000원

## 적용
1. ZIP 파일 내용을 GitHub `all-in` 저장소에 덮어 업로드
2. Supabase SQL Editor > New query
3. `ALLIN_V41_Supabase_Update.txt` 전체 붙여넣기
4. Run
5. 아이폰 Safari 새로고침
