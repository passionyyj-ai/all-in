# ALLIN V5.9.1 - 주 포지션 우선 필터 및 정렬

## 변경 내용

- 회원 명단의 포지션 필터는 주 포지션만 기준으로 적용합니다.
- 전체 회원 명단은 공격, 토스, 좌수비, 우수비의 주 포지션 순서로 묶고 같은 그룹 안에서는 이름순으로 정렬합니다.
- 보조 포지션은 회원 명단에 계속 표시되며 회원 추가·수정 시 그대로 관리할 수 있습니다.
- 회원 검색, 회원 수정, 회원 삭제 기능은 기존과 동일하게 유지합니다.
- PWA 캐시 버전을 V5.9.1로 갱신했습니다.

## 데이터베이스

이번 변경에는 Supabase SQL 업데이트가 필요하지 않습니다.
