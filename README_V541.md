# ALLIN V5.4.1

## 수정 사항
- V5.4에서 누락된 회원용 로그아웃 기능 복원
- 로그인 회원 이름 옆에 로그아웃 버튼 표시
- 로그아웃 시 회원 세션, PIN, 로그인 상태 초기화
- 로그인 화면으로 즉시 복귀
- 회원/총무 PWA 분리와 2~4팀 경기 등록 기능 유지
- PWA 캐시 버전 V5.4.1로 갱신

## 적용
Supabase SQL 실행은 필요하지 않습니다.

GitHub 운영 저장소 파일을 전부 교체한 후:
- Safari에서 기존 홈 화면 아이콘 삭제
- 회원용과 총무용을 각각 다시 홈 화면에 추가
