# ALLIN V5.7.1 총무 비밀번호 키보드 수정

## 원인
총무 로그인 비밀번호 입력칸에 `inputmode="numeric"`가 남아 있어
아이폰에서 숫자 키패드만 표시되었습니다.

## 수정
- 총무 로그인 비밀번호: 일반 영문/숫자/특수문자 키보드
- 현재 비밀번호 및 새 비밀번호 변경 입력칸도 일반 키보드로 명시
- 자동 대문자, 자동 수정, 맞춤법 검사 비활성화
- 회원 개인 PIN과 시스템 초기화 PIN은 기존 숫자 키패드 유지

## 적용
SQL 업데이트는 필요하지 않습니다.
GitHub 운영 저장소 파일을 교체하고 아이폰 앱을 완전히 종료한 뒤 다시 실행하세요.
