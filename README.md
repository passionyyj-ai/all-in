# ALLIN V4.8

## 게임비 미수 개선
- 미수 내역을 모임일별 카드로 표시
- 각 모임일별 회원 청구/납부/미납 표시
- 하단에 회원별 월 미납 합계 유지
- 동일 회원의 여러 모임 게임비 합산

## 공유
- 월 전체 미납자 단톡방 공유
- 특정 모임일 게임비 공유
- 회원 1명 개인 게임비 공유
- iPhone/Android Web Share API 사용
- 공유 버튼을 누르면 휴대폰 공유 시트가 열리며 설치된 카카오톡을 선택 가능
- 공유 API를 사용할 수 없는 브라우저는 문구를 클립보드에 복사

## 기존 기능 유지
- 회원 제외 운영 데이터 PIN 초기화
- 연도 이월
- 1/3/6/12개월 회비 납부
- 8:0 콜드패 즉시 시리즈 종료
