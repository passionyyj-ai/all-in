# ALLIN V5.6.4 관리자 비밀번호 변경

## 기능
- 총무 화면 상단에 `비밀번호 변경` 버튼 추가
- 현재 비밀번호 재확인
- 새 비밀번호 및 확인 입력
- Supabase Auth의 `admin@allin.club` 계정 비밀번호 즉시 변경
- 변경 후 자동 로그아웃
- 관리자 로그인에서 하드코딩된 `1111` 제거
- 로그인 화면에 입력한 비밀번호로 Supabase 인증

## 주의
운영 전용 화면은 더 이상 코드에 관리자 비밀번호를 보관하지 않습니다.
해당 기기에 유효한 총무 로그인 세션이 없으면 운영 모드 진입이 제한됩니다.

## 적용
SQL 업데이트는 필요하지 않습니다.
GitHub 운영 저장소 파일을 교체하고 캐시를 새로고침하세요.
