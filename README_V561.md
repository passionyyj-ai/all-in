# ALLIN V5.6.1 경기운영 전용 화면

## 신규 파일
- `operation.html`
- `operation.js`

## 동작
- 회원 화면에서 운영 버튼을 누르면 `operation.html`로 이동
- 관리자 로그인 화면은 표시하지 않음
- 회원 로그인 세션과 PIN을 다시 검증
- 참석과 경기운영 메뉴만 제공
- 회원관리, 회비, 미수, 시스템관리 화면은 표시하지 않음
- 상단에 현재 운영자 이름 표시
- 회원 화면으로 돌아가기 제공
- 회원 로그아웃 기능 유지

## 적용
별도 SQL 업데이트는 필요하지 않습니다.
GitHub 운영 저장소 파일을 모두 교체하고 강력 새로고침하세요.
