# 올인 족구단 V4.4

## 콜드패 규칙
- 세트 점수가 정확히 8:0이면 콜드패
- 8:0 발생 즉시 현재 시리즈 종료
- 이전 세트 승패/현재 시리즈 승수와 관계없이 8점 팀이 시리즈 승리
- 0점 팀원에게 1인당 4,000원 게임비 청구
- 시리즈 종료 후 팀 재편성 가능
- 새 팀으로 새로운 시리즈 진행

## 일반 경기
- 3판 2승 또는 5판 3승
- 최종 패배팀 1인당 2,000원

## 적용
1. ZIP 내용을 GitHub all-in 저장소에 덮어 업로드
2. Supabase SQL Editor > New query
3. ALLIN_V44_Supabase_Update.txt 전체 붙여넣기
4. Run
5. GitHub Pages 새로고침
