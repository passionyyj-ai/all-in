# ALLIN V5.7.7 시리즈 시작 오류 수정

## 원인
`startSeries()`에서 참석자 목록 변수 `people`을 선언하기 전에 사용하여
버튼 클릭 즉시 JavaScript 오류가 발생했습니다.

또한 Supabase에 이전 심판 기준이 남아 있으면 8명 이하에서도
심판을 요구할 수 있었습니다.

## 수정
- 참석자 목록을 먼저 생성한 뒤 심판 조건 계산
- 모임 미선택 예외 처리
- 4~8명: 심판 없음
- 9~11명: 심판 필수
- 12명 이상: 별도 심판 없음
- 총무용과 회원 경기운영 화면 모두 수정

## 적용
1. Supabase SQL Editor에서 `ALLIN_V577_Series_Start_Fix.sql` 실행
2. GitHub 운영 저장소 파일 교체
3. 모바일 앱 완전 종료 후 다시 실행
