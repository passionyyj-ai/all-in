# ALLIN V5.7.5 회원 PIN 기반 경기운영

## 해결된 오류
기존 경기운영 화면은 총무 Supabase 로그인 세션을 요구하여
회원 앱에서 바로 진입할 경우 `경기 운영 권한 세션이 없습니다` 오류가 발생했습니다.

## 변경
- 총무 앱 선로그인 불필요
- 회원 로그인 이름과 PIN을 다시 검증
- 경기운영 데이터는 전용 SECURITY DEFINER RPC로 조회
- 참석, 팀 편성, 팀 이동, 2팀/3팀 경기 운영 전용 RPC 추가
- 회원관리, 회비, 미수, 초기화 권한은 제공하지 않음

## 심판 기준
- 4~8명: 심판 없음
- 9~11명: 심판 1명 필수
- 12명 이상: 3팀 경기, 심판 없음

## 적용
1. Supabase SQL Editor에서 `ALLIN_V575_Operation_PIN_Auth.sql` 실행
2. 이전 V5.7 심판 SQL을 실행하지 않았다면 `ALLIN_V57_Attendance_Referee.sql`도 먼저 실행
3. GitHub 운영 저장소 파일 교체
4. 아이폰/안드로이드 앱 완전 종료 후 재실행
