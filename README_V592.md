# ALLIN V5.9.2

- 일반 시리즈와 3팀 시리즈 시작 화면에서 패배팀 1인당 게임비를 직접 입력합니다.
- 입력 금액은 시리즈에 고정 저장되고 진행 화면과 히스토리에 표시됩니다.
- 시리즈 종료 시 패배팀 게임비 청구에 입력 금액이 우선 적용됩니다.
- 총무 화면과 회원 경기운영 화면에 동일하게 적용됩니다.

## 적용

1. Supabase SQL Editor에서 `ALLIN_V592_Series_Manual_Fee.sql`을 실행합니다.
2. 배포 ZIP의 파일을 GitHub Pages 저장소에 덮어씁니다.
3. 앱을 완전히 종료한 뒤 다시 실행합니다.
