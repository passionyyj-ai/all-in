# ALLIN V5.7.2 회원용/총무용 PWA 분리

## 홈 화면 표시
- 회원 URL: `https://passionyyj-ai.github.io/all-in/`
  - 앱 이름: ALLIN 회원
  - 회원용 아이콘
  - 실행 시작점: index.html

- 총무 URL: `https://passionyyj-ai.github.io/all-in/admin.html`
  - 앱 이름: ALLIN 총무
  - 총무용 아이콘
  - 실행 시작점: admin.html

## iPhone
1. Safari에서 각 URL을 각각 연다.
2. 공유 → 홈 화면에 추가.
3. 기존 아이콘이 있다면 먼저 삭제한 후 다시 추가한다.

## Android
1. Chrome에서 각 URL을 각각 연다.
2. 메뉴 → 앱 설치 또는 홈 화면에 추가.
3. 회원용과 총무용을 각각 설치한다.

## 적용
SQL 업데이트는 필요하지 않습니다.
GitHub 파일을 교체한 후 기존 홈 화면 아이콘을 삭제하고 다시 추가해야
새 이름과 새 아이콘이 확실히 적용됩니다.
