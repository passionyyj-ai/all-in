# ALLIN V5.7

## 참석 상태
- 새 모임 생성 시 모든 회원은 미응답
- 총무 참석 저장 시 체크하지 않은 회원을 자동 불참 처리하지 않음
- 회원이 직접 불참을 선택한 기록은 유지
- 과거 버전에서 전원 불참으로 잘못 생성된 열린 모임은 미응답으로 정리

## 팀 편성
- 참석 4~11명: 2팀
- 참석 12명 이상: 3팀
- 참석자 전원을 팀에 균등 배정

## 심판
- 12명 미만의 2팀 시리즈 시작 시 참석자 중 심판 1명 필수 선택
- 심판은 팀 명단에 유지
- 해당 시리즈의 게임비 청구 제외
- 해당 시리즈의 개인 게임횟수 제외
- 회원 화면과 경기 운영 화면에 심판 표시

## 적용
1. Supabase SQL Editor에서 `ALLIN_V57_Attendance_Referee.sql` 실행
2. GitHub 운영 저장소 파일 교체
3. 아이폰 앱 완전 종료 후 재실행
