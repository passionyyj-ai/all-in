# ⚽ 올인 족구단 V4.0

## V4 변경
1. 회원 정보의 `나이`를 `출생연도`로 변경
   - 기존 나이 데이터는 SQL 적용 시 `현재연도 - 나이` 방식으로 출생연도를 임시 변환합니다.
   - 정확한 출생연도는 총무 화면에서 회원 수정으로 확인/보정하세요.

2. 자동 팀 생성 방식 추가
   - 포지션 균형 생성: 기존 방식
   - 완전 랜덤 생성: 포지션 무관, 참석자 무작위 4명씩 배정
   - 4명 미만 남는 인원은 대기

3. 회원 전용 조회 대시보드
   - 월별 회비 납부 현황
   - 당월 수입/지출 및 현재 잔액
   - 최근 수입/지출 내역
   - 월별 게임비 납부/미납 현황
   - 회원 화면에서는 조회만 가능

## 적용 순서
1. GitHub `all-in` 저장소의 기존 파일을 V4 ZIP 내용으로 덮어 업로드
2. Supabase SQL Editor → New query
3. `ALLIN_V4_Supabase_Update.txt` 전체 복사/붙여넣기
4. Run
5. GitHub Pages 배포 후 아이폰 Safari 새로고침

## 기존 V3.5 연납 회비 기능
전체 `supabase_setup.sql`에는 V3.5 회비 다개월/연납 SQL도 포함했습니다.
현재 DB에 V3.5 SQL을 이미 적용했다면 V4 추가 SQL만 실행하면 됩니다.
