# ALLIN V5.9.10 — 전체 참석자 재편성

참석 16명 중 팀 배정 12명·대기 4명을 재편성 대상 12명으로 계산하던 문제를 수정했습니다.

## 적용
V5.9.8/5.9.9를 적용한 기존 DB에서 ALLIN_V5910_Include_Waiting.sql을 실행한 뒤 웹 파일을 교체하고 앱을 다시 엽니다.
최초 4팀 업데이트라면 이전 hotfix → ALLIN_V598_Four_Teams.sql → ALLIN_V5910_Include_Waiting.sql 순서로 적용합니다.
진행 중인 시리즈를 끝낸 후 4팀을 선택하고 팀을 다시 생성하세요.

## 동작
- “대기자도 포함” 기본 체크: 팀 소속과 무관하게 attending=true인 전원을 편성 대상으로 계산.
- 참석 16명, 기존 배정 12명, 대기 4명도 편성 대상은 16명. 팀당 4명으로 4팀 생성.
- 중간 이탈자 등 기존 대기자를 제외하려면 “대기자도 포함” 해제. 이 경우 참석 수와 편성 대상 수는 다를 수 있음.
- 불참자는 체크 여부에 관계없이 제외. 모든 경우 팀당 4명 유지, 정원 초과자는 대기.
- 관리자·회원 운영 화면 모두 프런트와 서버에 동일한 포함 옵션 전달.
- 로컬 회귀 검증을 수행했으며 실제 Supabase 실행 및 실기기 확인은 아직 수행하지 않았습니다.
