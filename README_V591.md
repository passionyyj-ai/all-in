# ALLIN V5.9.1

## 추가 기능

- `미수` 메뉴에서 회원별 월 게임비 총 청구액과 잔액을 직접 수정할 수 있습니다.
- 변경 사유, 수정 전·후 금액, 수정 시각, 수정자를 별도 이력으로 보존합니다.
- 자동 생성된 `game_dues`는 수정하지 않고 차액만 누적하므로 이후 자동 계산과 충돌하지 않습니다.
- 시리즈 시작 순간 A/B/C팀과 대기 명단을 이름까지 스냅샷으로 보존합니다.
- 시리즈 히스토리에서 날짜, 차수, 경기 방식, 팀·대기 명단과 승패 결과를 함께 확인합니다.
- 기존 시리즈의 A/B 또는 A/B/C 저장 배열은 마이그레이션 시 자동으로 역채웁니다. 과거 대기 명단은 원본 데이터가 없어 복원하지 않습니다.

## 적용 순서

1. 기존 V5.9 환경에서 `ALLIN_V591_GameFee_Series_History.sql`을 Supabase SQL Editor로 실행합니다.
2. 배포 ZIP의 웹 파일을 GitHub Pages 저장소에 덮어씁니다.
3. 설치된 앱을 완전히 종료한 뒤 다시 실행합니다.

## 호환성

- 기존 테이블과 컬럼을 삭제하거나 이름을 바꾸지 않습니다.
- V5.9의 `ALLIN_V59_Remove_Referee.sql` 적용 상태를 기준으로 합니다.
- V5.9.1 SQL은 반복 실행해도 테이블·정책·트리거가 중복되지 않도록 작성했습니다.
